# F1 Agency - Vue 3 Project

Tento projekt je moderná, interaktívna webová stránka pre fiktívnu F1 agentúru, postavená na Vue 3 a Vite. Obsahuje pokročilé UI komponenty, animácie a tematický dizajn inšpirovaný svetom Formuly 1.

Kľúčové Vlastnosti

F1 Mega Menu Navbar: Dynamické navigačné menu s rôznymi layoutmi pre kategórie (Jazdci, Konštruktéri, Závody, História) a interaktívnym promo blokom.

Hero Video Sekcia: Úvodná sekcia s videom na pozadí a poskakujúcou šípkou pre scroll nadol.

Portfólio Grid s F1 Tímami: Mriežka obrázkov s asymetrickým rozložením a špeciálnym plávajúcim kurzorom, ktorý zobrazuje názov a farbu tímu.

Lando Norris Štatistiky: Komponent s animovanými počítadlami pre víťazstvá, pódiá a body.

Služby (Pirelli Pneumatiky): Prezentačná sekcia s prepínaním medzi rôznymi zmesami pneumatík, vlastným kurzorom a stránkovaním.

Video Reveal Footer: Unikátny "parallax" efekt, kde sa pätička stránky plynule vysúva spopod fixnutého videa pri scrollovaní.

Plávajúce UI (Floating UI): Bočný panel s pripnutými F1 ikonkami a tlačidlo pre návrat hore (Scroll to Top), ktoré sa zobrazí po odscrollovaní.

Príprava Projektu

Pre spustenie projektu lokálne postupuj nasledovne:

### Inštalácia závislostí
```
npm install
```
### Spustenie lokálneho vývojového servera
```
npm run dev
```
### Build pre produkciu
```
npm run build
```
